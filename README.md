## 概要
基本的な2D横スクロールアクションに道を自ら作る要素を追加したゲームです。

**ジャンル:** 2D横スクロールアクション
*   **プレイ人数:** 1人
*   **プレイ時間:** 30分程度
*   **ターゲット層:** カジュアルゲームが好きな方、短時間で遊びたい方

## 特徴・アピールポイント
*   ポイント1：シンプルな操作性とゲーム性
*   ポイント2：複数のギミック
*   ポイント3：ステージの中間地点機能

## 遊び方（操作方法）
### 操作方法
*   **移動:** `W` `A` `S` `D`
*   **ダッシュ:** `LeftShift` キー
*   **ジャンプ:** `Space` キー
*   **ポーズ:** `Esc` キー
*   **BuildMode:** `B` キー

### ルール
1. ルール：ゴールを目指す

## 開発環境
*   **ゲームエンジン:** Unity 2022.3.34f1
*   **開発言語:** C#
*   **主な使用アセット、素材:**
    *   [Pixel Art Woods Tileset and Background](https://assetstore.unity.com/packages/2d/environments/pixel-art-woods-tileset-and-background-280066)
    *   [Free Pixel Font - Thaleah](https://assetstore.unity.com/packages/2d/fonts/free-pixel-font-thaleah-140059)
    *   [ぴぽや倉庫](https://pipoya.net/sozai/assets/charachip/character-chip-1/)


## 導入手順・起動方法
1. 本リポジトリの [Releases](https://github.com/Kurama-Hiiti/Create-Load/releases) からZIPファイルをダウンロードします。
2. ダウンロードしたファイルを解凍します。
3. `CreateLoad.exe` を実行するとゲームが始まります。
**[UnityRoom](https://unityroom.com/games/createload)にもアップロードしているのでそちらからもプレイできます。**
